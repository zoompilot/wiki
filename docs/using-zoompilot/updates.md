# Updates and uninstalling

Keep zoompilot up to date through the device's Software settings.
You do not need a factory reset for a normal zoompilot update.
{ .zp-lede }

## update zoompilot

1. Park and connect the device to Wi-Fi.
2. Open **Settings → Software** and check for updates.
3. Let the download finish, then follow the on-screen install and restart instructions.
4. Check the version shown under Software after restarting.

Keep the device powered until the update finishes. The release channel
is `main`.

## update Jetlink

Jetlink is a separate app or service. Follow its
[update instructions](../jetlink/releasing.md), especially when a release
requires updating both Jetlink and the comma.

## stop using zoompilot

Turn assistance off before parking. To change software, use the device's
uninstall/reset option under **Settings → Software**, then follow the
custom-software setup for your chosen project.

Save settings and upload any recordings you need before resetting.
