# Steering and cruise controls

Steering and cruise control can stay active separately. Learn which
button turns each off before using zoompilot.
{ .zp-lede }

## Mazda with the default settings

| Your action | Steering | Cruise speed control |
| --- | --- | --- |
| Main cruise switch on | Enables steering when the car and device are ready. | Arms cruise; set a speed to start it. |
| Set cruise | Can assist when available. | Starts cruise at the selected speed. |
| Press the brake | Remains active. | Cancels cruise. |
| Press CANCEL | Remains active. | Cancels cruise. |
| Turn the main cruise switch off | Turns off. | Turns off. |

Use the car's normal resume control to resume cruise when it is safe.
Check the device status: steering still depends on the car's minimum
speed, lane-keeping switch, and availability.

!!! warning "Take control whenever needed"

    Steer and brake yourself whenever the situation requires it. Do not
    wait for a button or alert. Cancelling cruise does not necessarily
    turn steering off.

## changed the steering settings?

The settings that let steering work separately are called **MADS**
(Modular Assistive Driving System). Find them under **Settings → Steering**.
The brake-pedal behaviour can be set to Remain Active, Pause, or Disengage.
The table above assumes the defaults.

### optional Mazda TJA button

On cars with the physical TJA button, **Mazda TJA Button** can make that
button the steering switch. With this setting on:

- **TJA toggles steering.**
- **Main cruise controls cruise only.** Turning it off does not turn steering off.
- To turn both off, turn cruise off and use TJA to turn steering off.

Leave this option off unless your car has the button and you want separate
controls. Check your selection while parked.

## other cars

Buttons and minimum speeds vary. The MADS settings may be limited by your
car. Check the device's steering settings and your car's normal controls;
do not assume the Mazda table applies to another brand.
