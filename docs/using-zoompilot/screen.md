# Screen and alerts

Read the device's status and alert text before relying on assistance.
Steering and speed control are separate states.
{ .zp-lede }

## what to check

| You see | What to do |
| --- | --- |
| Calibration or model-loading message | Follow the instructions and wait until assistance is available. |
| A cruise set speed | Check the steering status separately. A set speed does not mean steering is active. |
| A speed-limit prompt | Read the requested speed and confirmation button. Only accept a change when it is safe. |
| Steering unavailable or a minimum-speed warning | Steer yourself. Check the message and your car's steering limits. |
| TAKE CONTROL | Take control immediately. Investigate the cause after parking. |
| A dashboard cruise, radar, or camera fault | Stop using assistance and follow [troubleshooting](../help/troubleshooting.md). |

The screen layout differs between comma 3X and comma 4. The comma 4 uses
shorter setting names; its speed-limit Information and Warning modes do
not show the same sign display as the comma 3X.

## why your set speed changes

[Slow for Curves](../features/smart-cruise.md) can lower the set speed for
a curve and restore it afterward. [Speed-Limit Assist](../features/speed-limit-assist.md)
can change it to a speed limit. Both are optional.

## Jetlink icon

A pulsing home-button icon means a model is downloading or preparing.
Green means ready when parked or active when driving. Orange means you
should read the alert. [Jetlink daily use](../jetlink/using-jetlink.md)
explains switching models and what happens if the connection drops.
