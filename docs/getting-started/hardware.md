# What you need

You need a supported comma device and the cable kit for your car.
Jetlink and a Mazda navigation SD card are optional.
{ .zp-lede }

## already have a comma?

A comma 3X or comma 4 with the correct car cable kit can run zoompilot.
Check [your car](supported-cars.md), then [install the software](install.md).

Hardware clones are supported only when they match the required hardware,
including the camera that checks driver attention. Ask before buying a
clone if you are unsure.

## buying your first device

1. **Check [compatibility](supported-cars.md).** Match your model and year, including any required factory equipment.
2. **Choose a comma device and matching kit.** The [comma shop](https://comma.ai/shop) lists the parts for each supported car.
3. **Follow [comma's physical setup guide](https://comma.ai/setup).** Mount the device and connect the cables before installing zoompilot.

The car-specific cable kit is also called a **harness**.

## optional extras

| Extra | What it adds |
| --- | --- |
| Mazda navigation SD card | Lets supported Mazdas supply speed-limit information from the car's sign-recognition system. |
| Downloaded maps | Map-based curve slowdowns and speed limits. Download your region through sunnylink; this is separate from Mazda's SD card. |
| Jetlink computer or phone | Runs a larger driving model alongside the comma. See [Jetlink requirements](../jetlink/index.md). |
| Compatible Mazda steering motor swap | May add steering down to a stop on an older Mazda. This is an advanced hardware modification, not part of normal setup. See [EPS swaps](../technical/car-identification.md#eps-swap). |
