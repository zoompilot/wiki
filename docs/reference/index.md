# Reference

Looking for a particular control? The [settings reference](../settings/index.md)
lists the device menus, defaults and requirements. You don't need to work
through it to set up zoompilot.
{ .zp-lede }

[How it works](../technical/index.md) covers the steering tune, curve
planner, car identification and cruise control in more detail. These
are the engineering notes behind the shorter feature guides.

The [glossary](../help/glossary.md) explains abbreviations and older names
you may see in Discord or sunnypilot guides.
