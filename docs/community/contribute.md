# Contribute

Help other drivers, report a problem, or contribute code and documentation.
{ .zp-lede }

## Ask and answer on Discord

The [zoompilot Discord](https://discord.gg/jFWkHC2uhh) is the main
community space. Ask setup questions, share how your car drives, and help
new owners.

## Report issues and send code

The source lives at
[github.com/zoompilot/zoompilot](https://github.com/zoompilot/zoompilot):

- Open an issue for bugs, with a route ID if you have one.
- Pull requests are welcome. Read
  [CONTRIBUTING](https://github.com/zoompilot/zoompilot/blob/main/docs/CONTRIBUTING.md)
  in the repository first.
- To set up a development environment, start with the [openpilot](../help/glossary.md#openpilot) guide
  [Turn the speed blue](https://docs.comma.ai/how-to/turn-the-speed-blue/),
  then [Connect to comma](https://docs.comma.ai/how-to/connect-to-comma/).
- To add support for a new car, start with comma's
  [car porting guide](https://docs.comma.ai/how-to/car-port/), then
  study the [Mazda port](../technical/car-identification.md) in this
  wiki.

## Improve this wiki

Use the edit icon beside a page title to open its source on GitHub.
Read `CONTRIBUTING.md` in the wiki repository for the workflow and
[the writing guide](style-guide.md) for style.

## Share driving feedback

Include a route ID and the time of the problem. [How to give feedback](feedback.md).
