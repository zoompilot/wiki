# Community

zoompilot is a community project. Useful driving feedback, help with
questions, and contributions to code or documentation are welcome.
{ .zp-lede }

## take part

- [Give feedback](feedback.md): describe what happened and share a drive for review.
- [Contribute](contribute.md): help with code, documentation, or community questions.
- [Join Discord](https://discord.gg/jFWkHC2uhh): discuss zoompilot with other drivers.
